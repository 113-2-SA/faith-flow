# ✝️ Faith Flow — 你的天主教靈修旅伴 · Your Catholic Spiritual Companion

> 陪你記錄信仰、探索真理、與教友同行。
> *Record your faith, explore the truth, and walk alongside fellow believers.*

Faith Flow 是一款以天主教信仰為核心的跨平台靈修 App（iOS / Android / Web），結合 **祈禱日記、AI 信仰問答、靈修抽卡對話、教友社群與世界教堂朝聖地圖**，並運用大型語言模型、語意向量搜尋與語音技術，協助使用者看見自己信仰成長的軌跡。

Faith Flow is a cross-platform (iOS / Android / Web) spiritual app centered on the Catholic faith. It brings together a **prayer journal, AI faith Q&A, spiritual card-drawing conversations, a believer community, and a world church pilgrimage map**, using large language models, semantic vector search, and speech technology to help users see how their faith grows over time.

🌐 **線上體驗 Live Demo（Web）**：<https://113-2-sa.github.io/faith-flow/>

## ✨ 功能特色 Features

### 📖 祈禱日記 Prayer Journal

- 每日記錄靈修心得，可附上標題、標籤與「靈感福音」經文
  *Write daily reflections with a title, tags, and an inspiring Gospel verse*
- 以 **Jina Embeddings** 產生向量、**Mistral AI** 分析情緒與主題
  *Entries are vectorized with **Jina Embeddings**; emotions and themes are analyzed by **Mistral AI***
- 支援關鍵字、標籤搜尋，以及透過 **pgvector** 的語意相似日記搜尋
  *Keyword and tag search, plus semantic similarity search powered by **pgvector***
- **週回顧**：每週日凌晨自動生成上週的靈修回顧與福音摘要，可轉成語音收聽，也能手動補齊缺漏的週次
  ***Weekly Review**: auto-generated every Sunday with a spiritual recap and Gospel summary, available as audio; missing weeks can be backfilled manually*
- **禱告回顧光點（Nudge）**：偵測相似主題的日記群組，以時間軸光點呈現禱告歷程，並可延伸到 AI 對話
  ***Prayer Nudge**: detects clusters of related entries and visualizes your prayer journey on a glowing timeline, with an option to continue in an AI chat*

### 💬 有答大師 AI Faith Mentor

- 採用 **Two-Agent** 架構 / *Built on a **Two-Agent** architecture:*
  - **知識回答**：連結 Magisterium 天主教教義資料庫，回答附教廷文獻引用來源
    ***Knowledge Agent**: grounded in the Magisterium Catholic teaching database, with citations to Church documents*
  - **陪伴回應**：偵測提問的情緒溫度，自動調整感性與理性的回應比重
    ***Companion Agent**: senses the emotional tone of a question and balances empathy with reasoning accordingly*
- 長按任一回應段落即可「引用追問」
  *Long-press any paragraph to quote it and ask a follow-up*
- 由 **Groq（Llama 3.3 70B）** 生成回答，透過 SSE 串流輸出，並支援對話紀錄管理（新增、重新命名、刪除）
  *Answers generated by **Groq (Llama 3.3 70B)** and streamed via SSE, with conversation management (create, rename, delete)*

### 💌 活水泉源 Living Water Cards

- 每週更新五張靈修主題卡，每天限抽一張
  *Five new spiritual theme cards every week — draw one per day*
- 抽卡後與 AI（**Groq**）針對主題展開深度對話
  *Have an in-depth AI conversation (powered by **Groq**) on the drawn theme*
- 對話結束後生成專屬**信箋**與意境插圖，可在收藏頁回顧
  *Receive a personalized **letter** and illustration afterward, saved to your collection*

### 🕊️ 心靈營火 Community Campfire

- 分享祈禱日記、週回顧摘要與活水信箋
  *Share journal entries, weekly reviews, and Living Water letters*
- 按讚（為貼文祈禱）、留言、留言按讚、轉發分享
  *Like ("pray for") posts, comment, like comments, and repost*
- 依最新／熱門排序，支援關鍵字搜尋與檢舉機制
  *Sort by latest or popular, search by keyword, and report inappropriate content*

### 🌍 朝聖之地 Pilgrimage Map

- 以 Google Maps / Leaflet 呈現世界與台灣各地教堂（聖殿、主教座堂、聖堂）
  *Explore churches in Taiwan and around the world (basilicas, cathedrals, churches) on Google Maps / Leaflet*
- 教堂詳細頁提供圖片、歷史介紹、影片與 **360° 全景**互動
  *Church pages include photos, history, videos, and interactive **360° panoramas***
- **線上錄音祈禱**：透過 WebSocket 與 Deepgram 即時語音轉文字，祈禱以十字架標記顯示在地圖上（可選擇匿名）
  ***Voice Prayer**: real-time speech-to-text via WebSocket and Deepgram; prayers appear as cross markers on the map (anonymous option available)*
- **許願聖地**：使用者可申請新增聖地，經管理者審核後加入地圖
  ***Holy Site Wishes**: users can propose new sites, which are added after admin review*

### 🔧 其他 Others

- Google / Email 登入（Firebase Authentication）
  *Google / Email sign-in (Firebase Authentication)*
- 禮儀年資訊、首次使用導覽（Page Tour）
  *Liturgical calendar info and first-time onboarding tour*
- 毛玻璃（Glass）主題介面、深淺色模式
  *Glassmorphism UI with light / dark mode*
- 管理者後台：許願聖地審核、社群檢舉處理
  *Admin panel for holy site review and community report moderation*

### 🤖 AI 模型應用 AI Model Usage

| 模型 / 服務 Model / Service | 用途 Purpose |
|------|------|
| **Groq** — `llama-3.3-70b-versatile` | 主要文字處理引擎：有答大師的回答生成與串流、活水泉源的靈修對話與信箋撰寫、靈修主題卡題目生成<br>*Primary text engine: AI Faith Mentor answers and streaming, Living Water conversations and letters, and spiritual card question generation* |
| **Ollama** — `qwen2.5:14b` | Groq 無法使用時的備援 LLM<br>*Fallback LLM when Groq is unavailable* |
| **Mistral AI** | 日記與提問的情緒分析、週回顧內容生成<br>*Emotion analysis for journal entries and questions; weekly review generation* |
| **Jina Embeddings v3** | 將日記轉為 1024 維向量，用於語意搜尋與禱告回顧<br>*Converts entries into 1024-dim vectors for semantic search and prayer nudges* |
| **Magisterium API** | 提供天主教教義知識與教廷文獻引用<br>*Catholic teaching knowledge and Church document citations* |
| **Deepgram** / **Edge TTS** | 語音祈禱轉文字 / 週回顧轉語音<br>*Speech-to-text for voice prayers / text-to-speech for weekly reviews* |

> 模型名稱可透過 `GROQ_MODEL`、`QWEN_MODEL` 環境變數調整。
> *Models can be changed via the `GROQ_MODEL` and `QWEN_MODEL` environment variables.*

## 🚀 快速開始 Getting Started

### 環境需求 Prerequisites

- Node.js 22+
- npm
- （選用 Optional）Docker — 本地 PostgreSQL / *for local PostgreSQL*
- （選用 Optional）Expo Go App 或 Android Studio / Xcode 模擬器 / *or an Android / iOS simulator*

### 1. 取得專案 Clone the repository

```bash
git clone https://github.com/113-2-SA/faith-flow.git
cd faith-flow
```

### 2. 啟動後端 Start the backend

```bash
cd faith_flow/my-backend
npm install
# 建立 .env 並填入環境變數 / Create .env (see below)
node server.js
```

> 後端修改後需重新啟動才會生效。
> *Restart the server after making backend changes.*

若要使用本地資料庫，在專案根目錄執行： / *To use a local database, run from the project root:*

```bash
docker compose up -d   # PostgreSQL → localhost:5433
```

> ⚠️ 正式資料以 **Supabase** 為準，`init.sql` 等本地 SQL 檔可能與實際 schema 不同步，詳見 [HANDOFF.md](HANDOFF.md)。
> *⚠️ **Supabase** is the source of truth. Local SQL files such as `init.sql` may be out of sync with the actual schema — see [HANDOFF.md](HANDOFF.md).*

### 3. 啟動前端 Start the frontend

```bash
cd faith_flow
npm install
# 建立 .env 並填入 EXPO_PUBLIC_* 變數 / Create .env with EXPO_PUBLIC_* variables
npx expo start          # 行動裝置（掃 QR Code）/ Mobile (scan QR code)
npx expo start --web    # 瀏覽器 / Browser
```

## 🔑 環境變數 Environment Variables

### 前端 Frontend — `faith_flow/.env`

| 變數 Variable | 說明 Description |
|------|------|
| `EXPO_PUBLIC_API_URL` | 後端 API 位址 / Backend API URL |
| `EXPO_PUBLIC_FIREBASE_*` | Firebase 專案設定 / Firebase project config |
| `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY` | Google Maps API 金鑰 / API key |
| `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` / `_IOS_CLIENT_ID` / `_ANDROID_CLIENT_ID` | Google 登入 OAuth Client ID / Google Sign-In OAuth client IDs |

### 後端 Backend — `faith_flow/my-backend/.env`

| 變數 Variable | 說明 Description |
|------|------|
| `DATABASE_URL` / `DIRECT_URL` | PostgreSQL（Supabase）連線字串 / Connection string |
| `FIREBASE_SERVICE_ACCOUNT_JSON` or `FIREBASE_SERVICE_ACCOUNT_PATH` | Firebase Admin 服務帳戶 / Service account |
| `GROQ_API_KEY` / `GROQ_MODEL` | Groq 文字生成（預設 `llama-3.3-70b-versatile`）/ Groq text generation |
| `QWEN_BASE_URL` / `QWEN_MODEL` | Ollama 備援 LLM（預設 `qwen2.5:14b`）/ Ollama fallback LLM |
| `MISTRAL_API_KEY` | 情緒分析 / Emotion analysis |
| `JINA_API_KEY` | 文字向量化 / Text embeddings |
| `MAGISTERIUM_API_KEY` / `MAGISTERIUM_MCP_URL` | 天主教教義知識庫 / Catholic teaching knowledge base |
| `DEEPGRAM_API_KEY` | 語音轉文字 / Speech-to-text |
| `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_R2_*` | 圖片儲存 / Image storage |
| `PORT` | 伺服器埠號 / Server port |

> 🔒 請勿將 `.env` 與 Firebase 服務帳戶金鑰（`*.json`）提交至版本控制。
> *🔒 Never commit `.env` files or Firebase service account keys (`*.json`) to version control.*

## 📡 API 概覽 API Overview

| 路徑前綴 Route Prefix | 功能 Purpose |
|----------|------|
| `/health` | 健康檢查 / Health check |
| `/api/auth`, `/api/user` | 登入驗證、使用者資料 / Authentication & user profile |
| `/api/diary` | 祈禱日記 CRUD / Journal CRUD |
| `/api/weekly-summary` | 週回顧（生成、查詢、語音）/ Weekly review (generate, query, audio) |
| `/api/nudge` | 禱告回顧光點 / Prayer nudges |
| `/api/chat`, `/api/conversation` | 有答大師對話 / AI mentor conversations |
| `/api/livingwater` | 活水泉源（抽卡、對話、信箋、收藏）/ Living Water (draw, chat, letters, collection) |
| `/api/post`, `/api/comments`, `/api/like`, `/api/comment-likes`, `/api/share` | 社群貼文與互動 / Community posts & interactions |
| `/api/search` | 日記與貼文搜尋 / Journal & post search |
| `/api/liturgical` | 禮儀年資訊 / Liturgical calendar |

除部分公開端點外，API 需在 Header 帶入 Firebase ID Token：
*Except for a few public endpoints, requests must include a Firebase ID token:*

```
Authorization: Bearer <Firebase ID Token>
```
